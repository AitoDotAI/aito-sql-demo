Ask a database why,
in plain SQL.

Root causes and the lever that moves each — no model trained, nothing precomputed. One SELECT, over the Postgres wire protocol.

-- why do hot-climate sites churn twice as often?
SELECT * FROM relate('hot_sites',
  to => 'churned = true',
  fields => 'cooling');
passive ×1.81
active ×0.79
liquid ×0.55

Passive cooling — but only where it is hot. Across the whole book it reads ×1.56; in temperate sites, ×1.08.
